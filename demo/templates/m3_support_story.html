MILESTONE 3 · DEMONSTRAÇÃO AO VIVO

Ana pede suporte.
Bruno pode consultar, não aprovar.

Ana é a titular da solicitação sintética. Bruno é o agente de atendimento. Um backend recebe JWTs emitidos após login real, solicita ao WSO2 um token delegado e consulta uma API protegida. A identidade da titular permanece em sub, e a do agente aparece em act.sub.

WSO2 7.3.18 · RFC 8693 · JWT + JWKS · Audience · Escopos

01 · Preparar identidades reais

Ana · titular

Capturar seu JWT com requests:read, por autenticação OIDC.

./scripts/m3-local.sh capture-subject --insecure-localAguardando

Bruno · agente

Capturar seu próprio JWT. O act.sub do token final deve apontar para Bruno.

./scripts/m3-local.sh capture-actor --insecure-localAguardando

Os JWTs são guardados somente em generated/m3-tokens/. Este navegador nunca os recebe.

Audience: verificando

02 · Executar operação de suporte usando WSO2

O servidor fará 3 trocas reais no endpoint OAuth do WSO2, validará o JWT assinado e enviará o token delegado por Authorization: Bearer à API de solicitações. A consulta retorna dados sintéticos, sem tocar em pedidos de produção.

Nenhuma transação executada nesta sessão.

03 · Linha do tempo da delegação

1. Login e confiança

WSO2 reconhece Ana e Bruno

PENDENTE

Assinaturas e identidades distintas ainda não verificadas.

2. Emissão RFC 8693

Bruno age em nome de Ana

PENDENTE

O token delegado deve preservar sub e act.sub, com escopo reduzido.

3. Recurso real por HTTP

Consultar solicitação de Ana

PENDENTE

GET protegido valida assinatura, issuer, audience e requests:read.

4. Tentativa indevida

Bruno tenta aprovar

PENDENTE

Uma aprovação requer requests:approve. A API deve devolver 403.

04 · Evidência de aceite

NÃO EXECUTADO

Limite da demonstração

A API de solicitações é um recurso sintético com verificações JWT reais. A operação de aprovação é uma prova de autorização e não altera o estado de um pedido. Integrar ao banco real de pedidos e às regras de negócio é uma etapa distinta. Isso não é uma simulação do token exchange.
